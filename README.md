
# Satellite Image Classification with CNN

This project trains a convolutional neural network to classify satellite images into 10 land-use classes.

The project includes:
- a Jupyter Notebook for model training
- a trained CNN model
- a Shiny app for image classification
- plots showing training performance and evaluation results

## Classes

The model predicts one of the following classes:

- AnnualCrop
- Forest
- HerbaceousVegetation
- Highway
- Industrial
- Pasture
- PermanentCrop
- Residential
- River
- SeaLake
